# RefAB — бесплатный плагин для сравнения микса с референсами

RefAB — аналог Metric AB: вешается на мастер, держит до 8 референс-треков и одной кнопкой переключает между вашим миксом (A) и референсом (B) с подгонкой громкости. Рядом идут спектр, LUFS и стереоизмерители для обоих сигналов.

Форматы: VST3 (Windows и macOS), AU (macOS). Проверен под REAPER.

## Установка

### macOS
1. Распакуйте `RefAB-macOS.zip`.
2. Скопируйте `RefAB.vst3` в `~/Library/Audio/Plug-Ins/VST3/`,
   а `RefAB.component` в `~/Library/Audio/Plug-Ins/Components/` (AU нужен не для REAPER, а для Logic и подобных DAW).
3. Плагин не подписан сертификатом Apple, поэтому один раз снимите карантин в Терминале:
   ```
   xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/RefAB.vst3
   xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/RefAB.component
   ```
4. В REAPER: Options → Preferences → Plug-ins → VST → **Re-scan**.

### Windows
1. Распакуйте `RefAB-Windows.zip`.
2. Скопируйте папку `RefAB.vst3` целиком в `C:\Program Files\Common Files\VST3\`.
3. В REAPER: Options → Preferences → Plug-ins → VST → **Re-scan**.

## Как пользоваться

1. Повесьте RefAB **последним** плагином на мастер-канал (после лимитера). Тогда в положении A вы слышите ровно то, что уходит в экспорт.
2. Перетащите референсы (WAV, AIFF, FLAC, MP3, OGG; на macOS ещё M4A/AAC) в список слева или кликните по пустому слоту. Частота дискретизации подгоняется под проект автоматически.
3. Жмите большую кнопку **A / B**. Чтобы переключать с клавиатуры или MIDI, в REAPER нажмите кнопку **Param** в окне плагина → **Learn** → параметр «A/B (Reference)».

### Сравнить два файла (без проекта)
У каждого трека в списке есть кнопки **A** и **B**:
- клик по треку (или по **B**) — он звучит в положении B;
- клик по **A** — этот файл звучит в положении A вместо звука из REAPER.

Плагин сам переключится в режим **Free**: жмите **Play** внизу, оба файла играют синхронно с одной позиции, громкость B подгоняется под A. Клик по волне перематывает оба. Чтобы вернуть в A звук проекта, нажмите строку **DAW mix** вверху списка.

Если в режиме Free нет звука, проверьте в REAPER: Preferences → Audio → включено «Run FX when stopped».

### Режимы воспроизведения
- **Restart** (по умолчанию): при каждом старте DAW референс играет с точки cue (белый треугольник) или с начала лупа. Удобно сравнивать припев с припевом.
- **Sync**: референс идёт по таймлайну проекта. Поставьте курсор DAW туда, где у вас начинается, например, припев, кликните на волне референса по его припеву и нажмите **Align to DAW**.
- **Free**: у референса своя кнопка Play, транспорт DAW не нужен.

### Волна референса
- Клик ставит точку cue (в режиме Free ещё и перематывает).
- Протяжка мышью задаёт луп. Края лупа можно двигать.
- Двойной клик убирает луп. Кнопка **Loop** включает и выключает его.

### Подгонка громкости
- **Integrated**: интегральная громкость референса (или только его лупа) приравнивается к интегральной громкости вашего микса. Самый честный режим. Кнопка **Reset meters** начинает измерение заново.
- **Live**: громкость подстраивается по short-term LUFS непрерывно, пока играют оба сигнала.
- **Ref trim** добавляет к референсу ещё ±24 дБ поверх подгонки.

### Мониторинг
- **Monitor**: Stereo / Mono / Side / L / R. Действует на то, что вы сейчас слушаете.
- **Band**: соло полосы. Low ниже 120 Гц, Lo-Mid 120 Гц–1 кГц, Hi-Mid 1–6 кГц, High выше 6 кГц.

### Анализ
- Спектр: синий — микс, оранжевый — референс, оба в 1/6 октавы. Референс показывается уже с подгонкой громкости. Кнопка **Difference** рисует разницу «референс минус микс»: выше нуля значит, что у референса в этой полосе больше.
- Таблица для A и B: Momentary, Short-term и Integrated LUFS, RMS, пиковый уровень, PLR (динамика), корреляция и ширина стерео (0 % — моно, 100 % — полностью широкий).
- Гониометр снизу справа.

Список референсов, точки cue, лупы и настройки сохраняются вместе с проектом. Если файл референса переместить, слот покажет ошибку: просто загрузите его заново.

## Сборка из исходников

**macOS, одной командой** (нужны только Xcode Command Line Tools; CMake скрипт скачает сам, если его нет):

```
cd путь/к/RefAB
bash build_mac.sh
```

Скрипт соберёт VST3 и AU и сразу установит их в `~/Library/Audio/Plug-Ins`.

**Вручную:** нужны CMake 3.22+ и компилятор: Xcode на macOS, Visual Studio 2022 на Windows. JUCE скачается сам.

```
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release --target RefAB_VST3
```

На GitHub сборка под обе системы идёт автоматически (`.github/workflows/build.yml`): после каждого push готовые архивы появляются во вкладке **Actions → последний запуск → Artifacts**.

## Лицензия

Плагин построен на фреймворке JUCE 8. Для личного некоммерческого использования ничего платить не нужно. Если будете распространять плагин, исходники должны оставаться открытыми (AGPLv3) или нужна лицензия JUCE.
